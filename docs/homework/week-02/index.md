# 第二周作业

## 项目选题
### 最终选题
智能安全老旧小区管理平台

### 选题确定过程
本次项目选题经过多次对比筛选，先后考虑过短视频项目、普通小区物业项目、宠物医院管理系统等方案。短视频项目存在媒体文件存储等复杂难点，开发难度较高；基础物业系统业务比较普通，缺少特色；宠物医院场景和本次设想的小区安全主题契合度不足。
结合课程项目需要循序渐进迭代、业务场景适合练习后端开发的要求，最终选定老旧小区安全管理平台。该场景工单、告警业务丰富，无硬件对接等高风险模块，工作量可控，适合本学期逐步开发。

## 功能规划
### 本周已完成内容
1. 确定项目名称、业务背景与适用场景，聚焦老旧小区安全管理。
2. 梳理4类角色：业主、访客、管理员、安全监测系统，整理各角色需求。
3. 划分基础功能模块，梳理报修、访客申请、隐患上报等核心业务流程。
4. 划定项目范围，区分当前可实现功能与暂不实现内容。
5. 初步规划后续可拓展的技术方向。

### 后续迭代计划
1. 搭建项目基础工程，设计数据库表结构。
2. 实现基础用户注册登录与角色权限判断。
3. 优先开发报修工单、访客申请、公告、隐患台账核心模块。
4. 根据课程进度，逐步尝试引入认证、消息等相关技术。
5. 在项目后期，视学习情况尝试服务拆分、简单监控与容器部署。
